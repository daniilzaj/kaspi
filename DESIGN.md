# Каспи — визуальная система

## Задача

Сотрудник управляющей компании видит общее число клиентов, события арендаторов и результат кампаний. Его действия — открыть клиентскую историю и найти аудиторию. Арендатор работает в отдельном портале: выбирает свой проект, загружает отчёт или настраивает API.

## Направление

Светлый операционный кабинет с синим акцентом. Главная показывает единый профиль как основной объект системы, рядом — фактические показатели. Логотип из сходящихся контуров отражает объединение разрозненных записей. В навигации нет декоративной схемы со стрелками; рабочие сущности описаны словами и данными.

## Токены

- Фон `#f3f6fb`, поверхность `#fff`, текст `#17243c`, вторичный `#6d7b92`.
- Основное действие `#2858d8`, мягкий акцент `#eaf0ff`, успешный статус `#2d916f`.
- Заголовки Manrope, основной текст DM Sans, технические метки IBM Plex Mono.
- Скругления 8–18 px, мягкие границы, без декоративных теней.
- Вся валюта — рубли (`₽`).

## Компоненты

- Кабинет УК: боковая навигация на десктопе, компактные вкладки на телефоне. Только обзор, клиенты и аудитории.
- Портал арендатора: линейный сценарий «выбрать проект → загрузить отчёт → посмотреть результат»; настройка API раскрывается отдельно.
- Главная: фокусная синяя область с живым числом профилей, рядом три фактические метрики.
- Таблицы превращаются в подписанные строки на телефоне.
- Источник API в портале арендатора: URL, путь к массиву, карта полей, проверка образца, сохранение, ручная синхронизация.
- Ошибки схемы показываются до импорта; секрет авторизации не отображается в списке.
